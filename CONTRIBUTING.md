# Contribuire

1. Crea un fork e un branch descrittivo.
2. Mantieni gli originali immutabili: anteprime e ridimensionamenti sono sempre derivati.
3. Non inserire credenziali, file astronomici o dati personali nel repository.
4. Verifica `npm run build` prima di aprire una pull request.
5. Descrivi modifiche, verifiche effettuate e migrazioni dati.

Segnalazioni di sicurezza: non aprire dettagli sfruttabili in una issue pubblica; contatta privatamente il maintainer.
